# Spot It! 🎮

## Project Description
![Spot It Game Screenshot](ss.jpg)
Spot It! is an interactive "Find the Differences" game where players compare two images and find the hidden differences before the timer runs out.

The game provides multiple difficulty levels with different images, number of differences, and time limits.

---

## Features

- 🎮 Start screen with easy navigation
- ⭐ Three difficulty levels:
  - Easy
  - Medium
  - Hard

- 🖼️ Compare two images and find hidden differences
- ⏱️ Countdown timer
- 🏆 Score tracking system
- 🔍 Differences counter
- 🎉 Win and lose result screens
- 🔊 Sound effects:
  - Timer sound
  - Win sound
  - Lose sound

- 🎊 Confetti animation when the player wins
- 🔄 Restart and Back buttons

---

## How to Play

1. Click the Start button.
2. Choose a difficulty level.
3. Find all differences between the two images.
4. Click on the correct areas.
5. Complete the level before the timer reaches zero.
6. Try to get the highest score!
